# 🎓 School Management System

A modern, scalable, and enterprise-level School Management System built using the MERN-style architecture with **React.js, Node.js, Express.js, MySQL, and JWT Authentication**. The platform streamlines school operations including student management, staff management, attendance, fees, timetable, examinations, events, and administrative workflows through a centralized dashboard.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/abhi-148/Menr_SchoolManagement.git
```

```bash
cd Menr_SchoolManagement
```

---

## Backend

```bash
cd backend
npm install
```

Create `.env`

```env
PORT=5000

DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=school_management

JWT_SECRET=school_secret_key

EMAIL_USER=your_email
EMAIL_PASS=your_password
```

Run

```bash
npm run dev
```

or

```bash
npm start
```

---

## Frontend

```bash
cd frontend
npm install
npm run dev
```
